# Zoom by Scroll — macOS

No extra software needed. macOS has built-in zoom with scroll support.

## Setup (one time)

1. Open **System Settings** → **Accessibility** → **Zoom**
2. Enable **"Use scroll gesture with modifier keys to zoom"**
3. Set the modifier key to **⌘ Command** (matches Win key on other platforms)
4. Click OK

That's it.

## Usage

| Action | Shortcut |
|--------|----------|
| Zoom in | `⌘ Command` + Scroll up |
| Zoom out | `⌘ Command` + Scroll down |

## Notes

- Works system-wide, in any app
- To adjust zoom speed: same menu → "Zoom style" → options
- If you prefer Option or Control instead of Command, choose whichever feels natural
